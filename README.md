# CPS5004 Data Analysis Assessment
## Air Quality and Public Health Analysis

### Project Description
This project analyses air quality and hospital admission data from five UK cities during 2023.

### Tools and Libraries
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- SciPy

### Main Analysis Tasks
1. Data preprocessing and cleaning
2. Outlier detection
3. Pollution Index calculation
4. Admissions per 100,000 population
5. Data normalisation and standardisation
6. One-hot encoding
7. Descriptive statistics
8. Independent t-tests
9. Pearson correlation analysis
10. Data visualisation

### Project Files
- `main.py` – Python analysis programme
- `AirQuality-Health-UK.csv` – Original dataset
- `cleaned_air_quality_data.csv` – Processed dataset
- `encoded_air_quality_data.csv` – One-hot encoded dataset
- PNG files – Analysis graphs

### How to Run
Open the project folder in VS Code and run:

`py main.py`
